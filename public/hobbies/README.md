# Homepage hobbies

Add entries to this folder, then rebuild and publish the portfolio. The homepage reads them in filename order. Start names with a number to choose their order.

- `01-walk-in-the-park.jpg` adds a photo. Use a descriptive filename because it supplies the image description. Supported formats are JPG, JPEG, PNG, WebP, AVIF, and GIF.
- `01-walk-in-the-park.txt` adds a caption to that photo. Match the name before the extension exactly.
- `02-movie-line.txt` adds a standalone entry. Write the quote and its source on separate lines, or use the file for a plain note.

Each entry needs its own base name. All languages show the same photos and the original text you write.
